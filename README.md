# UFC-335
Austin & Chantra House Party

## Run locally

Open `index.html` in a browser. Edit the `party` details near the top of `app.js` before sharing the invite. Replace `OIP.webp` (or update the image source in `index.html`) to change the intro splash image.

The RSVP list is a front-end preview stored in the browser's local storage. It is not shared between guests or devices; connect a backend to collect a centralized guest list.
